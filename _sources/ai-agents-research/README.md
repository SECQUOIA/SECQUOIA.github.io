# AI agents research post: source archive

The original author-supplied files for “AI Agents Can Already Do Research.
Now What?” are kept here:

- `blog.tex`: article text.
- `references.bib`: the complete supplied bibliography.
- `inventory.tex`: research inventory.
- `figures/research-setup.tex`: original TikZ procedure diagram.

The website version is
[`_posts/2026-09-28-ai-agents-can-already-do-research.md`](../../_posts/2026-09-28-ai-agents-can-already-do-research.md).
Jekyll excludes `_sources/` from the published site.

The post was converted with Pandoc 3.9 and citeproc using the IEEE numeric
citation style. Only cited bibliography entries appear in the post. The
LaTeX longtable was split into six HTML tables, preserving the row IDs,
claimed contributions, write-up links, and Lean statuses. Notes-only rows link\nto the corresponding area’s notes at the cited commit. Formulas are
rendered with MathJax. The procedure diagram is an accessible HTML ordered
list, styled as three cards that stack on narrow screens.

The Markdown post is the website's editable version; these files are its
source snapshot, not inputs to the Jekyll build. Changes to the LaTeX or
bibliography must also be applied to the post, including citation numbering
and reference anchors. Check all inventory rows and links after conversion.

The `preview/` directory contains desktop and phone screenshots for review.
It is excluded from publication along with the source archive.
